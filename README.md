# HKJC 15-feature app 修正版使用說明

## 部署

1. 先備份 GitHub repo 原有的 `app.py`。
2. 將 `app.py` 上載至 repo，改名為 `app.py`。
3. 確認同一層有模型檔 `my_hkjc_model.pkl`、（如使用獨立位置模型）`my_hkjc_place_model.pkl`、預測卡 `prediction.csv` 及歷史檔 `hkjc_all_seasons_features.csv`。
4. 把 `requirements.txt` 內容合併到 repo 的 `requirements.txt`，不可漏掉 `streamlit-autorefresh`，否則啟動時會因匯入缺失而失敗。
5. Streamlit Cloud 重新部署後，查看 Logs；本修正版已通過 `py_compile`、Streamlit AppTest 和隔離功能檢查。

## 修正內容

- 歷史騎師、練馬師、馬匹及近況統計按每個預測日重新計算，只用該日以前的可解析賽果；歷史檔缺失、日期無法識別或缺乏截止日前資料時停止，不會回退到整份歷史或假裝正常預測。
- 不再用 WIN 10.0、PLACE 1.5 等假賠率補缺；非退出馬欠有效WIN價時，該場不會輸出AI機率、EV或建議注碼。明確標示退出的馬不會阻擋其餘馬匹。
- 保留原有 GraphQL 即時賠率查詢、手動刷新、10／30／60／120／300秒自動刷新，以及凍結場次功能。HKJC尚未開盤或API拒絕時不會用假的價格頂替；自動刷新更新後會 rerun 以立即顯示最新資料。
- 關閉用同一批回測結果尋找最高ROI的單日參數尋優。參數選擇必須用較早賽期，較後賽期保留作時間外驗證。
- 回測逐匹配對官方結果；某場有非退出馬匹未配對時，該場整場略過，避免漏掉結果後改用次選馬。模擬注單未配對會顯示待核對且不納入ROI分母。
- 位置席數按有效出賽馬匹：少於4匹沒有PLACE席；4–6匹取前2名，7匹或以上取前3名。退出不算有效出賽；取消賽事／退出注單在模擬結算中退款。
- 平頭名次以名次字首解析；WIN命中按名次1辨識，正式派彩欄存在時優先用HK$10官方派彩。PLACE回測如沒有專用派彩則明確標為賠率估算；如命中注缺少任何可用派彩，該ROI會顯示「不計ROI」。
- QP不再用兩匹位置賠率乘固定倍率假造派彩。缺指定馬匹組合的官方QP派彩時，只顯示QP命中率，不計本金回收及ROI。
- 完成賽果下載器會探查最多15場並列出失敗場次；發現中間缺場時檔名帶 `PARTIAL`，不得當作完整賽日資料。

## 自動賠率操作

在預測頁勾選「自動更新未凍結場次」，再選刷新間隔；被凍結場次不更新。未開盤時程式保留已有值，不製造預設賠率。請確認該版本是否仍收到HKJC API資料；若HKJC回傳拒絕或空結果，介面會顯示錯誤而不是聲稱已更新。

> GraphQL端點為原程式使用的HKJC資料介面；程式只保留原有查詢方式，不採用代理、偽裝或繞過存取控制的方法。HKJC端點可能改動或拒絕請求，程式無法保證端點始終可用。
